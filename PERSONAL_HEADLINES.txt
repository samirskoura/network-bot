USE YOUR OWN 500 OR 800 HEADLINES - NO OPENAI KEY

1. Extract the complete ZIP on your computer.
2. Open headline_pool.txt in Notepad.
3. Replace ALL the sample lines with your own 400, 500 or 800 headlines.
   Put ONE headline on each line. Do not add numbers, bullets, quotation marks,
   column headings, or commas between separate headlines.
4. Each Arabic headline must fit within 34 characters, including spaces.
   Save as UTF-8 and keep the filename exactly headline_pool.txt.
5. Upload it with the complete package. For an existing bot, follow
   REPLACE_ALL_FILES.txt in the SAME repository with your existing Secrets.
6. In Actions -> Run workflow, choose:
     target_slot: your selected target (for example target_2)
     run_mode: test
     headline_source: manual
     max_updates: 80
     monitoring: one_check
7. Confirm the log says:
     Manual headline pool: ... distinct lines loaded; OpenAI is disabled.
   The number may be smaller if your file contains repeated or blank lines.
8. Check the target and preview count, then use live mode for actual edits.
   Keep headline_source=manual for live and overnight runs too.

HOW YOUR LIST IS USED
- Each eligible Creative takes the first suitable line in your file that it has
  not already used. File order is preserved.
- Different Creatives can use the same line, including 10 or 80 at once.
- After an edit, that Creative waits for review. A confirmed later rejection
  makes it eligible for its next unused suitable line.
- No headline is reused on that same Creative once it is in its saved history.
  Changes only to spacing, punctuation or Arabic diacritics still count as the
  same wording. Duplicate lines in the file are ignored.
- Distinct personal lines are allowed even when their wording is similar.
- A Creative that exhausts the list is skipped until you add more options. The
  bot does not wrap around to used lines. Other eligible Creatives can continue.
- APPROVED, PENDING and unknown review statuses remain protected. Existing
  linked-Ad checks and conditional Creative PATCH protections are retained.
- Lines that exceed 34 characters or contain an internal resource name are skipped.

800 headlines means 800 candidate options for each Creative. The separate limit
of 80 is the maximum number of eligible Creatives edited in one check.

SECRETS
Manual mode needs your Snapchat credentials and the state encryption key.
OPENAI_API_KEY and PRODUCT_CONTEXT are NOT required. Existing OpenAI Secrets can
remain; they are unused in manual mode. No OpenAI generation is requested.
Retain STATE_ENCRYPTION_KEY and the saved history in this same repository.

ADDING MORE LINES LATER
Update headline_pool.txt after the running job finishes, commit the file, then
start a new workflow run. A job already running uses its checked-out file.
Adding or reordering lines does not reset each Creative's usage history.

OPTIONAL AI MODES
manual_then_openai tries your list first, then asks OpenAI for remaining candidates.
openai generates suggestions directly. These modes need OPENAI_API_KEY and
PRODUCT_CONTEXT. Keep manual selected if you want only your own text.
