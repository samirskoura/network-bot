SNAPCHAT COMPLETE BOT - UP TO 80 CREATIVES

Already using this bot in GitHub?
Open UPGRADE_EXISTING_BOT.txt first. Update the existing repository and workflow.
Keep your existing Secrets, STATE_ENCRYPTION_KEY and state.json.enc so the bot
retains approval records and headline history. You do not need another token.

Creating a bot for a different Ad Account?
Open README.md and follow "New bot setup". Use a separate repository and a new
state encryption key for that account. Start without another account's state.
An existing valid refresh token can be used with its matching OAuth Client ID
and Client Secret if its authorized user can access the target account.

WHAT IS INCLUDED
- Complete snap_headline_bot.py with the 80-Creative ceiling and status guards.
- GitHub Actions workflow in .github/workflows/snapchat-headline-editor.yml.
- state_crypto.py and requirements.txt.
- 100 Arabic headline options and the existing blocked-headline hash list.
- PowerShell helpers for target IDs, OAuth tokens, and encryption keys.
- Setup guide, upgrade guide, and cross-organization authentication guide.

The ZIP contains source files, not your passwords, tokens, or saved account data.
GitHub installs the Python dependencies from requirements.txt during each job.

STATUS RULES
Only a DISAPPROVED Creative linked exclusively to REJECTED live Ads in your
selected squads can pass the checks. APPROVED, PENDING, PENDING_REVIEW, unknown
statuses, and links outside your selected squads block the edit.
Read README.md for the limitations when statuses change during a request.

FIRST RUN AFTER INSTALLING THIS VERSION
target_slot: target_1
run_mode: test
max_updates: 80
monitoring: one_check

Then verify one live edit with max_updates=1 and monitoring=one_check.
After that succeeds and encrypted state is saved, use max_updates=60 or 80.

WINDOWS HELPERS
Extract the ZIP first. In File Explorer, open the extracted folder, click its
address bar, type powershell, and press Enter. Run one of these commands:

Find Ad Squad IDs using your existing token:
powershell -NoProfile -ExecutionPolicy Bypass -File .\get_snap_ids.ps1

Generate a key ONLY for a new bot with no saved encrypted history:
powershell -NoProfile -ExecutionPolicy Bypass -File .\generate_state_key.ps1

Generate a refresh token ONLY if you need one:
powershell -NoProfile -ExecutionPolicy Bypass -File .\get_snap_token.ps1

The token and key helpers copy their result to your Windows clipboard.
Paste the value directly into the matching GitHub Secret.
