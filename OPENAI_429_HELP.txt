ERROR CODES
- credit_balance_exhausted: review prepaid API credits.
- organization_spend_limit_exceeded / project_spend_limit_exceeded: review the
  corresponding spend limit.
- organization_usage_limit_exceeded: review the approved API usage limit.
- insufficient_quota: review API billing, credits and limits.
- rate_limit_exceeded / slow_down: the bot waits and retries within its limits.
- unknown: the response does not establish the cause; do not assume expiry or
  depleted credit.
